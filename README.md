# Visual Editor
vanilla.js을 기반으로 한 가시적 오브젝트 편집도구

## 개발 환경
- Windows 11 Pro
- VSCode v1.111.0
	- Korean Language Pack for VisualStudio Code
	- Live Server
	- Claude Code
	- Outline
- Node.js v24.14.0

## 기반
- 자체 개발 중인 외부 의존성 없는 바닐라 경량 게임 프레임워크 (https://github.com/ddukbaek2/vanilla.js.git)   
- JSDoc 기반의 타입 힌팅
